Lesson 4: Live Search & List Filtering with FastAPI

Objective

Combine signal binding, debounced input events, and server-side filtering to build a real-time live search list using Datastar and FastAPI.

The Pattern

When a user types into a search box, Datastar updates the query signal and fires a debounced GET request to FastAPI. FastAPI filters an in-memory or database list and streams back the updated HTML fragment for the results list.

FastAPI Live Search Implementation

from fastapi import FastAPI
from fastapi.responses import HTMLResponse, StreamingResponse

app = FastAPI()

ITEMS = [
    "Datastar Framework",
    "FastAPI Python",
    "Server-Sent Events",
    "Tailwind CSS",
    "Hypermedia Systems",
    "Python AsyncIO"
]

@app.get("/", response_class=HTMLResponse)
def index():
    items_li = "".join([f"<li>{item}</li>" for item in ITEMS])
    return f"""
    <!DOCTYPE html>
    <html>
    <head>
        <script type="module" src="https://cdn.jsdelivr.net/gh/starfederation/datastar@v1.0.0-beta.7/bundles/datastar.js"></script>
    </head>
    <body>
        <div data-signals="{{query: ''}}">
            <input type="text" data-bind-query placeholder="Search items..." 
                   data-on-input__debounce.200ms="@get('/search')" />
            <div id="results">
                <ul>{items_li}</ul>
            </div>
        </div>
    </body>
    </html>
    """

@app.get("/search")
async def search(query: str = ""):
    filtered = [item for item in ITEMS if query.lower() in item.lower()]
    items_li = "".join([f"<li>{item}</li>" for item in filtered]) if filtered else "<li>No items found</li>"
    
    async def event_generator():
        fragment = f'<div id="results"><ul>{items_li}</ul></div>'
        yield f"event: datastar-patch-dom\ndata: fragments {fragment}\n\n"

    return StreamingResponse(event_generator(), media_type="text/event-stream")

Interactive Skill Check

Question: In this live search pattern, where does the filtering logic execute?

  • A) Strictly in client-side JavaScript
  • B) On the FastAPI backend server
  • C) Inside the browser CSS engine
  • D) Inside Datastar core extension

Answer: B) On the FastAPI backend server
