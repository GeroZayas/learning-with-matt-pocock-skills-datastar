Lesson 6: Using the Official `datastar-py` SDK with FastAPI

Objective

Learn how to correctly use the official Python SDK package datastar-py and its FastAPI helper module (`datastar_py.fastapi`) for clean, type-safe SSE responses and signal parsing.

The Official `datastar-py` API

Instead of manually constructing raw SSE strings, datastar-py provides:

  • DatastarResponse: Response class designed specifically for FastAPI/Starlette.
  • @datastar_response: Decorator that automatically wraps return values (including generators) into DatastarResponse.
  • read_signals(request): Async helper to extract incoming frontend signals.
  • ServerSentEventGenerator as SSE: Helper methods like SSE.patch_elements() and SSE.patch_signals().

Correct FastAPI Implementation with `datastar-py`

from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse
from datastar_py import ServerSentEventGenerator as SSE
from datastar_py.fastapi import DatastarResponse, datastar_response, read_signals

app = FastAPI()

@app.get("/", response_class=HTMLResponse)
def index():
    return """
    <!DOCTYPE html>
    <html>
    <head>
        <script type="module" src="https://cdn.jsdelivr.net/gh/starfederation/datastar@v1.0.0-beta.7/bundles/datastar.js"></script>
    </head>
    <body>
        <div id="counter" data-signals="{count: 0}">
            <p>Count: <span data-text="$count"></span></p>
            <button data-on-click="@get('/increment')">Increment</button>
        </div>
    </body>
    </html>
    """

@app.get("/increment")
@datastar_response
async def increment(request: Request):
    # Read incoming signals from Datastar request
    signals = await read_signals(request)
    current_count = int(signals.get("count", 0)) + 1

    # Return DOM patch using official SSE generator helper
    html_fragment = f'''
    <div id="counter" data-signals="{{count: {current_count}}}">
        <p>Count: <span data-text="$count">{current_count}</span></p>
        <button data-on-click="@get('/increment')">Increment</button>
    </div>
    '''
    return DatastarResponse(SSE.patch_elements(html_fragment))
