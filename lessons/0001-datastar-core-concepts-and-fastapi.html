Lesson 1: Datastar Core Concepts & FastAPI Setup

Introduction to Datastar & FastAPI

Datastar is a hypermedia-driven framework that brings reactive frontend behavior to server-rendered web applications using attributes like data-signals and data-on, communicating via Server-Sent Events (SSE).

FastAPI is an async Python web framework that makes streaming Server-Sent Events effortless using StreamingResponse.

In this first lesson, we will explore the mental model of Datastar (Signals, Actions, and Backend Patches) and wire up a minimal FastAPI endpoint.

Primary Source Recommendation

Read the official Datastar Getting Started Guide to understand how attributes are parsed and how SSE backend requests work in the open-source release.

Minimal FastAPI + Datastar Example

Here is how you set up a basic FastAPI backend that returns HTML fragments for Datastar:

from fastapi import FastAPI
from fastapi.responses import HTMLResponse

app = FastAPI()

@app.get("/", response_class=HTMLResponse)
def index():
    return """
    <!DOCTYPE html>
    <html>
    <head>
        <script type="module" src="https://cdn.jsdelivr.net/gh/starfederation/datastar@v1.0.0-beta.7/bundles/datastar.js"></script>
    </head>
    <body>
        <div id="counter" data-signals="{count: 0}">
            <p>Count: <span data-text="$count"></span></p>
            <button data-on-click="$count++">Increment</button>
        </div>
    </body>
    </html>
    """

Quick Check (Quiz)

Question: What protocol does Datastar use to stream DOM updates and signal patches from the backend?

  • A) WebSockets
  • B) Server-Sent Events (SSE)
  • C) Long Polling
  • D) gRPC

Answer: B) Server-Sent Events (SSE)
