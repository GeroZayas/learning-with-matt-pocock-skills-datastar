Lesson 3: Signals, Binding, & User Input with FastAPI

Objective

Learn how to capture user input using Datastar signals (`data-bind-*`) and send them to a FastAPI backend endpoint to generate reactive, dynamic UI responses.

Two-Way Binding with data-bind

Datastar allows you to bind inputs directly to signals without writing event handlers. For example, data-bind-name binds an input's value to the name signal. You can then send this signal state to FastAPI via query parameters or request bodies.

FastAPI Implementation for Live Input Echo with `datastar-py`

Here is how a FastAPI backend handles incoming signal data using read_signals and returns an HTML patch via DatastarResponse:

from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse
from datastar_py import ServerSentEventGenerator as SSE
from datastar_py.fastapi import DatastarResponse, datastar_response, read_signals

app = FastAPI()

@app.get("/", response_class=HTMLResponse)
def index():
    return """
    <!DOCTYPE html>
    <html>
    <head>
        <script type="module" src="https://cdn.jsdelivr.net/gh/starfederation/datastar@v1.0.0-beta.7/bundles/datastar.js"></script>
    </head>
    <body>
        <div data-signals="{name: ''}">
            <input type="text" data-bind-name placeholder="Enter your name..." 
                   data-on-input__debounce.300ms="@get('/greet')" />
            <div id="greeting">
                <p>Hello, <span data-text="$name || 'stranger'"></span>!</p>
            </div>
        </div>
    </body>
    </html>
    """

@app.get("/greet")
@datastar_response
async def greet(request: Request):
    signals = await read_signals(request)
    name = signals.get("name", "stranger")
    
    fragment = f'<div id="greeting"><p style="color: #0284c7; font-weight: 600;">Server says: Hello, {name or "stranger"}!</p></div>'
    return DatastarResponse(SSE.patch_elements(fragment))

Interactive Skill Check

Question: What attribute modifier is commonly used on input events in Datastar to prevent hammering the backend on every single keystroke?

  • A) __throttle
  • B) __debounce
  • C) __delay
