Lesson 5: Using FastAPI & SSE Starlette Correctly with Datastar

Objective

Ensure our FastAPI backend correctly formats Server-Sent Events (SSE) using industry-standard libraries like sse-starlette, ensuring robust event streaming and clean Datastar signal parsing.

Why `sse-starlette`?

While raw StreamingResponse works, sse-starlette is the standard production-grade library for FastAPI and Starlette that handles client disconnects, keep-alive heartbeats, and event formatting natively.

Production-Ready FastAPI + Datastar Example

from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse
from sse_starlette.sse import EventSourceResponse

app = FastAPI()

@app.get("/", response_class=HTMLResponse)
def index():
    return """
    <!DOCTYPE html>
    <html>
    <head>
        <script type="module" src="https://cdn.jsdelivr.net/gh/starfederation/datastar@v1.0.0-beta.7/bundles/datastar.js"></script>
    </head>
    <body>
        <div id="counter" data-signals="{count: 0}">
            <p>Count: <span data-text="$count"></span></p>
            <button data-on-click="@get('/increment')">Increment</button>
        </div>
    </body>
    </html>
    """

@app.get("/increment")
async def increment(request: Request):
    # Datastar automatically sends signals as query params on GET requests
    # Extract query params or handle state here
    
    async def event_generator():
        # HTML fragment to patch back into the DOM
        html_fragment = '<div id="counter" data-signals="{count: 1}"><p>Count: <span data-text="$count">1</span></p><button data-on-click="@get(\'/increment\')">Increment</button></div>'
        
        yield {
            "event": "datastar-patch-dom",
            "data": f"fragments {html_fragment}"
        }

    return EventSourceResponse(event_generator())
