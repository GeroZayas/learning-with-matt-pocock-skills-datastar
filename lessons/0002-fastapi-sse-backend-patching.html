Lesson 2: Server-Sent Events & FastAPI Backend Patching

Objective

Learn how FastAPI can stream Server-Sent Events (SSE) to Datastar, enabling server-driven DOM patches without writing custom client-side JavaScript.

FastAPI SSE Endpoint Implementation with `datastar-py`

Using the official datastar-py SDK and its FastAPI helpers, streaming Server-Sent Events with datastar-patch-elements is clean and type-safe: 

from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse
from datastar_py import ServerSentEventGenerator as SSE
from datastar_py.fastapi import DatastarResponse, datastar_response

app = FastAPI()

@app.get("/", response_class=HTMLResponse)
def index():
    return """
    <!DOCTYPE html>
    <html>
    <head>
        <script type="module" src="https://cdn.jsdelivr.net/gh/starfederation/datastar@v1.0.0-beta.7/bundles/datastar.js"></script>
    </head>
    <body>
        <div id="result">
            <button data-on-click="@get('/stream-update')">Fetch Server Update</button>
        </div>
    </body>
    </html>
    """

@app.get("/stream-update")
@datastar_response
async def stream_update(request: Request):
    html_fragment = '<div id="result"><p style="color: #0284c7; font-weight: 600;">Successfully updated using official datastar-py SDK!</p></div>'
    return DatastarResponse(SSE.patch_elements(html_fragment))

Interactive Skill Check

Question: When streaming element patches via the official Python SDK, which event type is generated behind the scenes?

  • A) message
  • B) datastar-patch-elements
  • C) update-html
  • D) dom-swap

Answer: B) datastar-patch-elements
