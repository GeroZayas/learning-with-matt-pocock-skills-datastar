Lesson 2: Server-Sent Events & FastAPI Backend Patching

Objective

Learn how FastAPI can stream Server-Sent Events (SSE) to Datastar, enabling server-driven DOM patches without writing custom client-side JavaScript.

FastAPI SSE Endpoint Implementation

In Datastar, backend actions make a request (e.g. via data-on-click="@get('/backend-endpoint')") expecting an SSE stream. Here is how you build that in FastAPI using StreamingResponse: 

from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse, StreamingResponse
import asyncio

app = FastAPI()

@app.get("/", response_class=HTMLResponse)
def index():
    return """
    <!DOCTYPE html>
    <html>
    <head>
        <script type="module" src="https://cdn.jsdelivr.net/gh/starfederation/datastar@v1.0.0-beta.7/bundles/datastar.js"></script>
    </head>
    <body>
        <div id="result">
            <button data-on-click="@get('/stream-update')">Fetch Server Update</button>
        </div>
    </body>
    </html>
    """

@app.get("/stream-update")
async def stream_update():
    async def event_generator():
        html_fragment = '<div id="result"><p style="color: green;">Successfully updated from FastAPI SSE!</p></div>'
        # Format according to Datastar SSE specification
        yield f"event: datastar-patch-dom\ndata: fragments {html_fragment}\n\n"

    return StreamingResponse(event_generator(), media_type="text/event-stream")

Interactive Skill Check

Question: When streaming a DOM patch via SSE to Datastar, what event name does Datastar listen for by default?

  • A) message
  • B) datastar-patch-dom
  • C) update-html
  • D) dom-swap

Answer: B) datastar-patch-dom
