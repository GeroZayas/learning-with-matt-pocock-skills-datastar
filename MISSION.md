# Mission: Master Datastar with FastAPI (Free/Open-Source Edition)

## Objective
Learn how to build hypermedia-driven, reactive web applications using **Datastar** paired with **FastAPI** in Python, sticking strictly to the free, open-source core features and community version (avoiding any paid/PRO features).

## Motivation
- Build lightning-fast, reactive web apps without the complexity of traditional heavy Single Page Application (SPA) frameworks (like React, Vue, or Svelte) on the frontend.
- Keep backend logic cleanly in Python using FastAPI, leveraging Server-Sent Events (SSE) and hypermedia (HTML over the wire) as championed by Datastar.
- Understand the core primitives of Datastar (`data-signals`, `data-on`, `data-computed`, `data-effect`, backend SSE merging/patching) in a Python/FastAPI environment.

## Success Criteria
1. Understand Datastar attributes and backend SSE integration in FastAPI.
2. Build interactive components (counters, forms, live search/filtering) using Datastar + FastAPI SSE endpoints.
3. Keep completely within the open-source scope (no PRO plugins, advanced enterprise add-ons, or paid tooling).
