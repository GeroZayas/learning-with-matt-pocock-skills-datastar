# Reference: Official Datastar Python SDK (`datastar-py` & FastAPI) - **PyPI Package:** `datastar-py` - **Official Repo:** [starfederation/datastar-python](https://github.com/starfederation/datastar-python) ## Official FastAPI Integration Pattern The official `datastar-py` package provides framework-specific response classes and decorators for FastAPI: - `datastar_py.fastapi.DatastarResponse` - `datastar_py.fastapi.datastar_response` (decorator) - `datastar_py.fastapi.read_signals` (signal extraction) - `datastar_py.ServerSentEventGenerator as SSE` ### Example Implementation with FastAPI: ```python import asyncio from fastapi import FastAPI, Request from fastapi.responses import HTMLResponse from datastar_py import ServerSentEventGenerator as SSE from datastar_py.fastapi import DatastarResponse, datastar_response, read_signals app = FastAPI() @app.get("/", response_class=HTMLResponse) def index(): return """

Count:

""" @app.get("/increment") @datastar_response async def increment(request: Request): # Read signals sent by Datastar frontend signals = await read_signals(request) current_count = int(signals.get("count", 0)) + 1 # Return DatastarResponse using SSE helper html_fragment = f'''

Count: {current_count}

''' return DatastarResponse(SSE.patch_elements(html_fragment)) ```
