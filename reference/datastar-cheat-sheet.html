Reference: Datastar Core Attributes & SSE Protocol

Core Attributes Cheat Sheet (Open Source)

  • data-signals="{key: value}": Initializes reactive state variables in the DOM element tree.
  • data-text="$variable": Binds text content reactively to a signal.
  • data-on-click="expression": Executes expressions or actions on click events.
  • data-bind-inputName: Two-way data binding for input elements (inputs, checkboxes, selects).
  • data-on-input__debounce.300ms="...": Event modifiers like debounce for efficient server requests.

Server-Sent Events (SSE) Protocol for Datastar

Datastar uses standard SSE with custom event types or data formats to merge fragments into the DOM:

event: datastar-patch-dom
data: fragments <div id="target">Updated HTML</div>
data: selector #target
data: merge morph
