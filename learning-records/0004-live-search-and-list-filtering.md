# Learning Record 0004: Live Search & List Filtering with FastAPI

- **Date:** 2026-08-05
- **Topic:** Building server-driven live search and list filtering using Datastar signals and FastAPI backends.
- **Key Insights:**
  - Live filtering combines `data-bind` for query input, debounced input events (`__debounce`), and backend SSE patching.
  - Offloading filtering logic to Python (FastAPI) keeps the frontend lightweight and adheres strictly to hypermedia-driven principles.
