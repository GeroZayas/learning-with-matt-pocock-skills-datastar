# Learning Record 0001: Datastar Core Concepts and FastAPI Setup

- **Date:** 2026-08-05
- **Topic:** Datastar core attributes, signals, client-side reactivity, and FastAPI HTML/SSE setup (Open-Source Edition).
- **Key Insights:**
  - Datastar uses HTML attributes (`data-signals`, `data-on-*`, `data-text`) to enable reactive frontends without heavy JavaScript build steps.
  - FastAPI integrates seamlessly by serving HTML templates or responses, and can stream Server-Sent Events (SSE) for dynamic server-driven DOM patching.
  - Keeping strictly to open-source primitives ensures zero licensing complexity and lightning-fast developer feedback loops.
