# Learning Datastar with FastAPI

This repository is the result of using the Matt Pocock `/teach` skill to learn and master **Datastar** paired with **FastAPI** (strictly using free, open-source core features).

## Technologies & Software Learned
- **[Datastar](https://data-star.dev/)**: A hypermedia-driven reactive frontend framework that uses HTML attributes (`data-*`) and Server-Sent Events (SSE) to update the DOM without heavy client-side SPAs.
- **[FastAPI](https://fastapi.tiangolo.com/)**: A modern, high-performance Python web framework for building APIs and async server endpoints.
- **[datastar-py](https://github.com/starfederation/datastar-python)**: The official Python SDK for Datastar, providing helper utilities (`DatastarResponse`, `@datastar_response`, `read_signals`, and `ServerSentEventGenerator`) for seamless backend-driven SSE patches.
